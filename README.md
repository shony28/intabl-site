# Intabl — головна сторінка

Цей публічний репозиторій містить тільки файли сайту https://2828.pp.ua.

- index.html — головна сторінка.
- CNAME — домен.
- sitemap.xml — головна й інструкція запуску; robots.txt — посилання на цю карту та автоматичний індекс магазинів на API.
- GitHub Pages: main → /(root).

Код магазинів, кабінету та API зберігається окремо в приватному репозиторії intabl.

Товарні карти автоматично формує CasaOS із опублікованого короткого індексу. Вони не копіюються в цей репозиторій. На тестовому домені meta robots noindex залишається до окремого рішення про публічну індексацію.

Головна тепер містить пошук та публічні результати з API (до 20 за запит); start.html — інструкція й копіювання шаблону. assets містить лише CSS, браузерний JS і відкритий довідник КАТОТТГ. Пошук не має секретів і не передає облікові дані. PHP, БД, ключі й кабінет залишаються в приватному intabl та CasaOS.
